# Catalyst Canvas v1.3.0

## Persistent Projects and Workspace Management

Version 1.3.0 turned the single-brief demonstration into durable project workspaces.

### Delivered

- Workspace Project Contract 1.0.
- Stable workspace and project identities, lifecycle metadata, tags, search, duplicate, archive, and restore.
- Immutable revision history for manual saves, autosaves, imports, and restoration.
- Idempotent migration of v1.2 `canvas_briefs` records into the default workspace.
- Backward-compatible numeric export URLs.
- Flask dashboards, revision history, autosave APIs, and workspace boundaries.
- Browser-local WordPress projects, revisions, save, autosave, duplicate, archive, and restore.

Canvas documents in this historical release used `catalyst-canvas/1.0`.
