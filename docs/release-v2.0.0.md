# Catalyst Canvas v2.0.0 Release

**Release:** Connected Strategic Design Platform  
**Contract:** `catalyst-canvas/2.0`  
**Exchange:** `catalyst-canvas-exchange/2.0`

Version 2.0.0 completes the v1.x build map by connecting research, evidence, ideation, decisions, experiments, collaboration, and publication to explicit first-party platform workflows.

## Release outcomes

- One canonical Contract 2.0 across Python, Flask, CLI, and WordPress
- Persistent platform connection and workflow records
- Institutional interoperability profiles
- Deterministic exchange packages and checksums
- Optional HMAC-SHA256 signing and verification
- Cross-product event envelopes and correlation IDs
- Capability discovery API
- Unified platform-readiness indicators
- v1.0–v1.6 migration with stable identity preservation
- Release validation, plugin packaging, and database-preserving installer

## Boundary

This release supplies interoperable contracts and local verification. It does not claim that external endpoints are online, that credentials are valid, that an exchange was delivered, or that a receiving institution accepted the data.
