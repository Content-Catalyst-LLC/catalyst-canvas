# Migration to Catalyst Canvas v1.9.0

Version 1.9.0 upgrades saved projects to Canvas Contract 1.6 when they are read, imported, saved, or reused.

Contract 1.5 projects retain all existing research, decisions, prototypes, experiments, and identifiers. New collaboration arrays are normalized. When no member list exists, the active workspace owner is represented as the default owner record.

Migration does not publish any project. Publication records, approvals, reviews, and redaction notes must be created explicitly.
