# Catalyst Canvas v1.8.0 Release

**Release:** Prototype and Experiment Management  
**Contract:** `catalyst-canvas/1.5`  
**Workspace contract:** `catalyst-canvas-workspace/1.0`

## Delivered

- Versioned prototype portfolio
- Falsifiable hypothesis register
- Participant, metric, and safeguard planning
- Structured experiment-run records
- Learning decisions and iteration history
- Flask Experiment Studio and APIs
- Browser-local WordPress experiment workspace
- Research Lab and Workbench experiment handoffs
- Contract 1.0–1.4 migration
- Cross-surface Contract 1.5 fixture
- Expanded release validation and package inspection

## Release boundary

The release records what was planned, observed, and decided. It does not claim that an experiment is statistically powered, ethically approved, causally valid, safe, or generalizable unless those judgments are established by the appropriate external process.
