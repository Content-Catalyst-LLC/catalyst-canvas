# WordPress Demo Workflow

1. Upload and activate `catalyst-canvas-demo-v1.4.0.zip`.
2. Add `[catalyst_canvas_demo]` to the public Canvas page.
3. Enter the challenge, audience, goal, constraint, and framework.
4. Add persona research, stakeholder map entries, and journey stages.
5. Generate and save the browser-local project.
6. Copy research-aware Markdown, download Contract 1.1 JSON, or print the report.

The demo does not transmit visitor inputs. Projects, revisions, personas, stakeholders, and journeys are stored only in the current browser's localStorage.
