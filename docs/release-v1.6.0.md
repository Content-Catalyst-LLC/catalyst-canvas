# Catalyst Canvas v1.6.0

## Framework and Ideation Studio

Version 1.6.0 adds the structured ideation layer required to turn framed challenges and research findings into traceable prototype candidates.

### Release scope

- Canvas Contract 1.3
- migration from Contracts 1.0, 1.1, and 1.2
- ten data-driven built-in framework packs
- custom organization frameworks
- reusable prompt packs
- divergent and convergent ideation sessions
- idea cards, tags, rationale, votes, clusters, merges, and selections
- challenge-to-HMW-to-idea-to-prototype lineage
- accessible cluster ordering controls
- framework-package API and CLI import/export
- Flask and browser-local WordPress studio parity
- deterministic Python, Flask, and Node conformance

### Release boundary

Ideation records preserve participant judgment and decision history. They do not certify that a concept is valuable, equitable, feasible, effective, or ready for implementation.
