# Catalyst Canvas Export Spec

A Canvas export should preserve:

- generated timestamp;
- challenge;
- audience;
- goal;
- constraint;
- selected framework;
- persona;
- point of view;
- HMW prompts;
- ideation prompts;
- prototype concept;
- test plan;
- assumptions;
- review questions.

See `schemas/catalyst_canvas_brief.schema.json` for a machine-readable schema.
