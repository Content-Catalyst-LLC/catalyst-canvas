# Migration to Catalyst Canvas v2.0.0

Version 2.0.0 upgrades saved projects to Canvas Contract 2.0 when they are read, imported, saved, or reused.

## Supported sources

- Canvas Contract 1.0
- Canvas Contract 1.1
- Canvas Contract 1.2
- Canvas Contract 1.3
- Canvas Contract 1.4
- Canvas Contract 1.5
- Canvas Contract 1.6
- Supported legacy v1.0 and v1.1 payload shapes

## Preservation rules

Migration preserves stable Canvas, revision, persona, stakeholder, journey, source, evidence, claim, assumption, framework, idea, decision, prototype, experiment, review, approval, publication, and release identities.

New Contract 2.0 platform collections are normalized from supplied metadata or initialized as empty collections. Migration does not invent verified connections, remote record IDs, signatures, delivery acknowledgements, or institutional approval.

## Review requirement

Migrated projects include provenance identifying the source contract and a review warning. Maintainers should verify endpoints, authentication modes, accepted contracts, retention policies, workflow relationships, and any carried exchange status before operational use.
