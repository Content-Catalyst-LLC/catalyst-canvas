# Catalyst Canvas Demo v1.4.0

The `[catalyst_canvas_demo]` shortcode provides a private browser-local project and design-research workspace.

## Capabilities

- generate Canvas Contract 1.1 documents through the shared browser engine;
- capture structured persona research with confidence and validation state;
- map stakeholders by influence, interest, stance, role, and strategy;
- build ordered journey stages with actions, pain points, opportunities, touchpoints, metrics, emotion, and ownership;
- create and switch saved projects;
- save manual and autosave revisions;
- duplicate and archive projects;
- migrate Canvas Contract 1.0 records;
- export canonical JSON and research-aware Markdown;
- retain all inputs in localStorage without transmitting them to Sustainable Catalyst.

## Install

Upload `catalyst-canvas-demo-v1.4.0.zip`, activate it, and place `[catalyst_canvas_demo]` on a page.

Browser projects are device- and browser-specific. Clearing site data removes the workspace.
