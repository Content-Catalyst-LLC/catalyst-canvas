# Catalyst Canvas Demo v1.8.0

The WordPress shortcode plugin provides a browser-local Catalyst Canvas workspace.

It can:

- generate and validate Canvas Contract 1.5 documents;
- persist projects and revisions in localStorage;
- edit research, evidence, ideation, prioritization, prototypes, hypotheses, experiment plans, runs, learning decisions, and iterations;
- migrate Canvas Contracts 1.0 through 1.4;
- export canonical JSON and Markdown and print a report;
- preserve Research Librarian, Knowledge Library, Decision Studio, Research Lab, and Workbench handoff plans.

Visitor inputs remain in the current browser and are not submitted to Sustainable Catalyst.

Upload `catalyst-canvas-demo-v1.8.0.zip`, activate it, and place `[catalyst_canvas_demo]` on a page.
