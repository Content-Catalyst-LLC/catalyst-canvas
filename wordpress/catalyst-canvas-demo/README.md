# Catalyst Canvas Demo v2.0.0

The WordPress shortcode plugin provides a browser-local Catalyst Canvas workspace using Canvas Contract 2.0.

It can:

- generate, validate, migrate, and export Canvas Contract 2.0 documents;
- persist projects and immutable browser revisions in localStorage;
- edit research, evidence, ideation, prioritization, prototypes, experiments, members, reviews, comments, approvals, publications, platform connections, interoperability profiles, workflow links, exchange records, and events;
- migrate Canvas Contracts 1.0 through 1.6;
- export complete canonical JSON, public-safe JSON, Markdown, print reports, and deterministic platform exchange packages;
- preserve Research Librarian, Knowledge Library, Site Intelligence, Decision Studio, Research Lab, Workbench, Product Support, Contact and Engagement, WordPress, and public API relationships;
- report platform readiness without claiming that configured remote services are reachable or authorized.

Browser exchange packages include SHA-256 integrity metadata. Server-managed HMAC signing belongs in the Flask or institutional service layer; signing keys are never stored in the public shortcode interface.

Public-safe downloads omit private collaboration and participant records. Visitor inputs remain in the current browser and are not submitted to Sustainable Catalyst.

Upload `catalyst-canvas-demo-v2.0.0.zip`, activate it, and place `[catalyst_canvas_demo]` on a page.
