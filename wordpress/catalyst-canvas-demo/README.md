# Catalyst Canvas Demo v1.9.0

The WordPress shortcode plugin provides a browser-local Catalyst Canvas workspace.

It can:

- generate and validate Canvas Contract 1.6 documents;
- persist projects and immutable browser revisions in localStorage;
- edit research, evidence, ideation, prioritization, prototypes, experiments, members, review assignments, comments, approvals, publication records, and release history;
- migrate Canvas Contracts 1.0 through 1.5;
- export complete canonical JSON, public-safe JSON, Markdown, and print reports;
- preserve Research Librarian, Knowledge Library, Decision Studio, Research Lab, Workbench, WordPress, and public API handoff plans.

Public-safe downloads omit private collaboration and participant records. Visitor inputs remain in the current browser and are not submitted to Sustainable Catalyst.

Upload `catalyst-canvas-demo-v1.9.0.zip`, activate it, and place `[catalyst_canvas_demo]` on a page.
