# Catalyst Canvas Demo WordPress Plugin

Adds a guided Catalyst Canvas demo to WordPress using the shortcode:

```text
[catalyst_canvas_demo]
```

Optional title/subtitle:

```text
[catalyst_canvas_demo title="Catalyst Canvas Demo" subtitle="Turn a messy problem into a structured design-thinking brief."]
```

## What it does

- Runs entirely client-side in the browser.
- Helps visitors frame a challenge, audience, goal, and constraint.
- Generates a draft persona, POV statement, HMW prompts, idea list, prototype card, and test plan.
- Supports JSON export, copy-to-clipboard, print, reset, and local browser persistence.

## Boundary

This demo supports structured design thinking. It does not validate a business model, certify impact, replace research, or make professional recommendations.
